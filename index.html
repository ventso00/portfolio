SmartWater — Système intelligent de gestion de l'eau

Contexte : Projet scolaire & personnel mené à l'ISPM Antsobolo (Licence 3 ESIIA), dans le cadre de la spécialisation IoT et systèmes embarqués. L'objectif était de concevoir un système intelligent capable d'analyser la qualité de l'eau en temps réel, de décider automatiquement des actions à mener (alerte, filtration) et de filtrer l'eau selon les seuils définis.

🎯 Objectifs du projet

  • Mesurer en continu les paramètres physico-chimiques de l'eau (capteurs IoT)
  • Transmettre les données vers un serveur PHP/MySQL via API REST
  • Afficher un dashboard temps réel avec historique et statistiques
  • Automatiser la décision : déclencher la filtration si seuil critique dépassé

🛠️ Architecture technique

  • Frontend / Backend : PHP 8, HTML5, CSS3, JavaScript (dashboard responsive)
  • Base de données : MySQL (mesures, historique, utilisateurs)
  • API REST : insert.php, get_status.php pour la communication capteurs ↔ serveur
  • IoT : capteurs connectés (ESP32 / Arduino), protocoles de communication
  • Présentation : 15 scènes immersives pour vulgariser le projet devant un jury

💼 Compétences professionnelles démontrées

  • Full-stack : développement PHP/MySQL complet (front + back + API)
  • IoT & embarqué : interfaçage capteurs, protocoles de communication
  • Data visualisation : dashboard avec graphiques statistiques et historique
  • Gestion de projet : conception, développement, déploiement, présentation jury
